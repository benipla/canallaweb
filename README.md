# Comedia Canalla - Instrucciones de Instalacion

## Estructura de Carpetas Requerida

Para que la web funcione correctamente en GitHub Pages, debes crear la siguiente estructura de carpetas:

```
tu-repositorio/
├── index.html
└── assets/
    └── images/
        ├── beni-pla.jpg
        ├── tarek.jpg
        ├── galeria-1.jpg
        ├── galeria-2.jpg
        ├── galeria-3.jpg
        ├── galeria-4.jpg
        └── galeria-5.jpg
```

## Archivos de Imagenes Necesarios

### Hosts del Show (Formato Recomendado: Cuadrado, 600x600px minimo)
- **beni-pla.jpg** - Foto de Beni Pla (se mostrara en circulo a la izquierda del titulo)

### Galeria (Formato Recomendado: Cuadrado, 800x800px para mejor calidad)

## Pasos para Subir a GitHub

1. Crea un nuevo repositorio en GitHub
2. Crea la carpeta `assets/images/` en tu repositorio
3. Sube el archivo `index.html` a la raiz del repositorio
4. Sube todas las imagenes a la carpeta `assets/images/`
5. Activa GitHub Pages en la configuracion del repositorio:
   - Ve a Settings > Pages
   - En "Source", selecciona "main" branch
   - Guarda los cambios
6. Tu sitio estara disponible en: `https://tu-usuario.github.io/nombre-repositorio/`

## Notas Importantes

- Todas las imagenes deben estar en formato JPG o PNG
- Se recomienda optimizar las imagenes antes de subirlas (usa herramientas como TinyPNG)
- Los nombres de archivo son sensibles a mayusculas/minusculas
- Asegurate de que los nombres de archivo coincidan exactamente con los especificados arriba
- Las imagenes de los hosts se ven mejor con fondo oscuro o neutro para que resalten con el borde rojo
